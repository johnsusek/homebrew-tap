# Johnsusek Tap

## How do I install these formulae?

`brew install johnsusek/tap/<formula>`

Or `brew tap johnsusek/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "johnsusek/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
